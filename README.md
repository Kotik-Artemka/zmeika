# COIL — Небесные сады
Небольшая самостоятельная 3D игра для **Godot 4.4.1+**, без плагинов и внешних ассетов.

## Запуск
Скачайте репозиторий через Code → Download ZIP, распакуйте.
В Godot нажмите **Import**, выберите **project.godot**, затем **F6/F5**.
Нужна обычная версия Godot, .NET не требуется.

## Игра
Соберите минимум 24 из 32 кристаллов, поднимитесь на четвёртый этаж
и нажмите E у маяка. На каждом этаже 8 кристаллов.
Зелёная площадка в углу (8, −8) — лифт: E поднимает на этаж выше.
Отверстия спускают на этаж ниже, на нижнем этаже отнимают жизнь.
Красные патрули отнимают жизнь. Всего три жизни; после попадания
действует короткая неуязвимость. Кристаллы удлиняют хвост и восстанавливают энергию.

- W/S: вперёд / назад
- A/D: поворот
- Мышь: обзор камеры за змейкой
- Shift: ускорение, расходует восстанавливающуюся энергию
- E: лифт / финиш у маяка
- Esc: пауза и настройки

## Производительность
Compatibility / OpenGL, простая геометрия, без тяжёлых текстур и постобработки.
Тени выключены по умолчанию и включаются в меню.
Этажи над игроком скрываются, чтобы не перекрывать камеру.
Рекорд сохраняется в user://save.cfg. Звук синтезируется в игре.
Производительность на конкретном слабом ПК не измерялась.

## Реализация
Main.tscn — точка входа; game.gd — арена, модель, движение, интерфейс и звук.
Геометрия создаётся при запуске: в редакторе сцена до запуска пустая.
Визуальный стиль вдохновлён цветной многоэтажной настольной ареной
и зелёной сегментированной игрушкой; модель стилизованная, не точная копия фото.
Проверено: импорт и headless запуск Godot 4.4.1.
